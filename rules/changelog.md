# Changelog Maintenance

- Every release must have a corresponding CHANGELOG.md entry
- Follow conventional changelog format (Keep a Changelog)
- Sections: Added, Changed, Fixed, Removed, Deprecated
- No PR numbers, branch names, or contributor attributions in entries
- No "Future Changes" or speculative sections
- Entries should describe what changed from a user/operator perspective
- Remove completed hotfix details once released to production
